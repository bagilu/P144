依據提供的 index(1).html 視覺樣式，以及《資訊架構與內容建置標準指引 V1.1》建立。
日期：2026-11-22。此為架構及版型審閱稿，內容供後續微調。

## 使用

完整解壓縮，保留目錄結構。上傳 P144/ 內所有內容至 GitHub Pages 專案根目錄。
本機建議在 P144 目錄使用 `python -m http.server 8000`，瀏覽 http://localhost:8000/。
直接雙擊 index.html 可查看版面，但瀏覽器可能阻擋讀取公告 JSON；請用本機伺服器預覽完整功能。

## 首頁公告

實際檔案：data/news.json；載入程式：assets/js/news.js。
目前為空陣列，畫面明示尚未提供正式公告。沒有建立 news.html、獨立消息詳情頁或資料庫。

有正式資料後，預設顯示 6 則，每次再增加 10 則；收合回到 6 則。各則可在原位開啟完整內容。
NEWS_INITIAL_COUNT 可調為 6–10；NEWS_LOAD_MORE_COUNT 預設 10。

以下是欄位格式示意，請以核定資料取代後才寫入公開 JSON：

```json
[
  {
    "id": "N0001",
    "published_at": "YYYY-MM-DD",
    "event_at": "YYYY-MM-DD",
    "category": "分類",
    "title": "正式公告標題",
    "summary": "簡述",
    "detail": "完整文字，可包含換行；不執行 HTML。",
    "url": "https://官方連結",
    "visible_from": "YYYY-MM-DD",
    "visible_until": "YYYY-MM-DD",
    "status": "published",
    "priority": "normal",
    "related_page": "p42.html"
  }
]
```

選填欄位無資料時可省略。日期使用 YYYY-MM-DD，顯示時間以 Asia/Taipei 判斷。
priority 可為 normal、important、pinned。到 visible_until 後解除優先排序，保留於依日期排序的消息中。
置頂與重要消息應填優先期限，並定期檢視。僅顯示已發布、發布日已到且符合 visible_from 的消息。
公開 JSON 本身可下載，切勿把草稿、未公開內容、個資或機密資料放入，即使程式會隱藏也不可以。
外部連結僅允許 http/https，開新分頁並標示。
